# Contributing

This repository is a read-only mirror, published automatically from the SerpKite
monorepo. Issues and pull requests are welcome here. Maintainers port accepted
changes upstream, and the next sync brings them back.

`openapi/serp-api.yaml` (where present) is the SerpKite v1 OpenAPI contract that the
SDK's types are generated from and checked against. Don't edit it here.
